## 🌟 મુખ્ય વિશેષતાઓ (Key Features)

1. **સાયબરપંક એસ્થેટિક્સ અને વિઝ્યુઅલ ઈફેક્ટ્સ (Cyberpunk Aesthetics)**:
   - Dynamic 3D Matrix & Neural Particle Canvas જે માઉસ સાથે મુવ થાય છે.
   - Laser Scanning Hologram Avatar કાર્ડ વિથ લાઈવ સિસ્ટમ ટેલિમેટ્રી (CPU, RAM, Uptime).
   - Chromatic Glitch Headings & Neon HUD Glassmorphism.

2. **લાઈવ ઈન્ટરેક્ટિવ સાયબર ટર્મિનલ (Interactive Terminal CLI)**:
   - ટર્મિનલમાં `help`, `skills`, `projects`, `contact`, `gujarati`, `matrix`, `sound`, `clear` કમાન્ડ રન કરી શકાય છે.
   - શોર્ટકટ બટનો દ્વારા એક ક્લિકમાં કમાન્ડ્સ એક્ઝિક્યુટ થાય છે.

3. **વેબ ઓડિયો સાયબર સાઉન્ડ સિન્થેસાઈઝર (Web Audio Synthesizer)**:
   - કોઈ પણ એક્સટર્નલ ફાઈલ વગર પ્યોર બ્રાઉઝર સાઉન્ડ સિન્થેસાઈઝર (હોવર, ક્લિક અને ટાઈપિંગ સાઉન્ડ).
   - એક જ ક્લિકમાં `SFX: ON / OFF` ટોગલ કરી શકાય છે.

4. **લાઈવ પ્રોફાઈલ કસ્ટમાઈઝર (Live In-Browser Profile Editor)**:
   - નીચે જમણી બાજુએ આપેલા ⚙️ **Gear Button** પર ક્લિક કરીને તમે બ્રાઉઝરમાં જ તમારું **નામ, ટાઈટલ, ફોન, ઈમેલ, વોટ્સએપ નંબર અને બાયો** બદલી શકો છો!
   - ફેરફારો આપોઆપ સેવ થઈ જશે અને તરત જ આખી વેબસાઈટમાં અપડેટ થઈ જશે.

5. **ફ્લેગશિપ પ્રોજેક્ટ બ્લુપ્રિન્ટ્સ અને મોડલ (Flagship Case Studies)**:
   - 3D ટિલ્ટ ઈફેક્ટ્સ સાથેના પ્રોજેક્ટ કાર્ડ્સ.
   - 'VIEW BLUEPRINT' પર ક્લિક કરવાથી ડિટેઈલ્ડ આર્કિટેક્ચર સ્પેક્સ સાથે મોડલ ખુલે છે.

6. **ડાયરેક્ટ કોમ્યુનિકેશન (Direct Comm-Link)**:
   - ઇન્સ્ટન્ટ વ્હોટ્સએપ (WhatsApp Quick Connect) લિંક.
   - એન્ક્રિપ્ટેડ કોન્ટેક્ટ ફોર્મ અને ડાયરેક્ટ ઈમેલ.

## 🚀 વેબસાઇટ કેવી રીતે ચલાવવી (How to Run)

તમે આ વેબસાઇટને નીચેની ૩ રીતોમાંથી કોઈપણ એક રીતે ખોલી શકો છો:

### રીત ૧: ડાયરેક્ટ ઓપન (સૌથી સરળ)
- ફોલ્ડરમાં રહેલી **`START_PORTFOLIO.bat`** ફાઈલ પર ડબલ ક્લિક કરો!  
  *(આ ફાઈલ આપોઆપ તમારા કમ્પ્યુટરના ડિફોલ્ટ બ્રાઉઝરમાં વેબસાઈટ ખોલી દેશે.)*

### રીત ૨: સીધી `index.html` ફાઈલ દ્વારા
- ફોલ્ડરમાં રહેલી **`index.html`** ફાઈલ પર ડબલ ક્લિક કરો અથવા રાઈટ ક્લિક કરીને તમારા મનપસંદ બ્રાઉઝર (Chrome / Edge / Brave) માં ઓપન કરો.

### રીત ૩: લોકલ સર્વર દ્વારા (Node.js)
```bash
npm start
```
અને બ્રાઉઝરમાં જુઓ: **`http://localhost:3000`**

## 💻 ટર્મિનલ કમાન્ડ્સ (Interactive Terminal Commands)

વેબસાઇટના ટર્મિનલમાં નીચે મુજબના કમાન્ડ્સ ટાઈપ કરી શકાય છે:
- `help` : તમામ કમાન્ડ્સની વિગતવાર યાદી
- `whoami` / `bio` : ડેવલપર આઈડેન્ટિટી અને ડિગ્રી
- `skills` : ટેકનિકલ સ્કિલ્સ મેટ્રિક્સ (React, Node, Postgres, Python)
- `projects` : ૫ મુખ્ય પ્રોજેક્ટ્સની યાદી
- `resume` : ૧-પેજ ATS રેઝ્યૂમે સમરી અને ડાઉનલોડ લિંક
- `inspect [name]` : પ્રોજેક્ટ સેન્ડબોક્સ (quickstaff, skillswap, tender, budgeteda)
- `ai [question]` : રિદ્ધિ AI કેરિયર આસિસ્ટન્ટને પ્રશ્ન પૂછવો
- `canvas [mode]` : કેનવાસ મોડ બદલવો (particles, matrix, warp)
- `ping` : રિયલ-ટાઇમ નેટવર્ક લેટન્સી ચેક
- `github` : ગિટહબ કમિટ્સ અને રિપોઝિટરી ટેલિમેટ્રી
- `stats` : એકેડેમિક પર્સેન્ટેજ (BCA 62.3%, HSC 75.3%, SSC 77.8%)
- `gujarati` : સ્થાનિક પરિચય (ગુજરાતી બાયો)
- `contact` : સંપર્ક વિગતો (ઈમેલ, ફોન, વોટ્સએપ)
- `matrix` : મેટ્રિક્સ રેઈન મોડ ટોગલ કરવો
- `sound` : સાઉન્ડ ઈફેક્ટ્સ ચાલુ/બંધ કરવા
- `clear` : સ્ક્રીન સાફ કરવી
