## 5. Featured Academic & Practical Projects

The portfolio showcases five flagship projects reflecting hands-on software development and data analysis experience:

### 1. Skill Swap Platform
* **Description:** A web-based application where users exchange skills without monetary transactions. Users can offer their expertise (e.g., coding, design, language) and learn new skills from peers, promoting collaborative community learning.
* **Tech Stack:** PHP 8, MySQL, Apache, HTML5, CSS3, JavaScript.
* **Local Source Archive:** Available in project <code>downloads/skill_swap.zip</code>.
* **Key Features:** User skill profiling, swap request matching, interactive dashboard, and real-time community feed.

### 2. QuickStaff: On-Demand Workforce & Staff Management System
* **Description:** A full-stack on-demand staffing and workforce management platform engineered with React.js, Express, and PostgreSQL. Features secure API authentication with protected endpoints, multi-role access (Admin Dashboard, Client Booking Portal, Worker Shift Management), and real-time staff browsing.
* **Tech Stack:** React.js (Vite), Node.js, Express.js REST API, API Authentication (JWT), PostgreSQL.
* **Local Source Archive:** Available in project <code>downloads/quick_staff.zip</code>.
* **Key Features:** Secure token-based API authentication, role-based route guards, multi-module architecture, worker profiles and skills filtering, shift dispatching, and booking logs.

### 3. Subscription Tracker
* **Description:** A web application that enables users to centralize, monitor, and manage their recurring digital subscriptions in a single dashboard.
* **Tech Stack:** HTML5, CSS3, JavaScript (ES6+), LocalStorage / Node.js.
* **Key Features:** Renewal date tracking, monthly expense breakdown, visual category charts, and deadline reminder alerts.

### 4. Government Tender & Bidding Portal
* **Description:** An electronic procurement and bidding portal designed to digitize public sector tenders, enhancing transparency and reducing paperwork.
* **Tech Stack:** Angular, HTML5, CSS3, JavaScript, Node.js, Express, MongoDB.
* **Local Source Archive:** Available in project <code>downloads/government_tender_portal.zip</code>.
* **Key Features:** Administrative tender publishing, vendor online bid submission, encrypted document uploads, and evaluation tracking.

### 5. Marriage Budget Analysis: Exploratory Data Analysis (EDA) Using Python
* **Description:** An analytical data project that evaluates wedding expenditure patterns across multiple expense categories using Python data science libraries.
* **Tech Stack:** Python, Pandas, Matplotlib, Seaborn, Google Colab / Jupyter Notebook.

## 7. How to Run the Portfolio Locally

1. **One-Click Startup (Windows):**  
   Double-click the file `START_PORTFOLIO.bat` inside the project folder. It starts the local server and opens your browser automatically.

2. **Terminal / Command Prompt Execution:**
   ```bash
   # Navigate to the project directory
   cd port-folder

   # Start the Node.js server
   node server.js
   ```
   Open your browser and visit: **`http://localhost:3000`**

   Open `index.html` directly in any modern browser (Google Chrome, Microsoft Edge, Brave, or Mozilla Firefox).
